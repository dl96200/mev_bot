# MEV 机器人系统详细设计文档

## 1. 总体架构

```
+------------------+      +------------------+      +---------------------+
|  数据采集层      | ---> |  策略引擎层       | ---> |  执行/交易层         |
|  (mempool/DEX)   |      |  (套利/清算)     |      |  (bundle/发送)      |
+------------------+      +------------------+      +---------------------+
          |                         |                           |
          v                         v                           v
+------------------+      +------------------+      +---------------------+
|  风控与资金管理  | <--> |  模拟与定价      | <--> |  监控与日志         |
+------------------+      +------------------+      +---------------------+
```

## 2. 模块设计

### 2.1 数据采集层
- **功能**：订阅区块、mempool、DEX 状态、借贷协议状态。
- **输入**：RPC/WebSocket，索引服务（TheGraph/自建索引）。
- **输出**：标准化池子状态、可交易机会事件。
- **关键组件**：
  - Block Watcher
  - Mempool Listener
  - Pool State Cache (V2/V3)

### 2.2 策略引擎层
- **功能**：识别机会、计算收益、生成交易计划。
- **策略模板**：
  1. **DEX-DEX 套利**：跨池/跨协议（V2 <-> V3）。
  2. **闪电贷套利**：在单 tx 中借贷、交易、还款。
  3. **清算策略**：识别健康因子低于阈值的账户，执行清算。
  4. **Backrun**：跟随大额交易做反向套利。
- **核心计算**：
  - 滑点与手续费计算
  - Gas 成本预测
  - 链上状态模拟（eth_call 或 fork 模拟）

### 2.3 模拟与定价模块
- **功能**：对候选交易进行预模拟，确保收益为正。
- **设计**：
  - 静态模拟：价格与手续费估算
  - 动态模拟：调用链上模拟环境
  - 可插拔接口，支持 tenderly/自建 fork

### 2.4 执行/交易层
- **功能**：构建交易、签名与发送。
- **支持通道**：
  - 公共 mempool
  - 私有交易通道（Flashbots/MEV-Share）
- **交易类型**：
  - 单 tx
  - Bundle（多交易打包）
- **Gas 策略**：动态 gas price + priority fee。

### 2.5 风控与资金管理
- **功能**：控制风险、资金隔离与限额。
- **策略**：
  - 最大交易额限制
  - 最小利润阈值
  - 交易失败次数熔断
- **密钥管理**：硬件签名 / KMS。

### 2.6 监控与日志
- **指标**：成功率、收益、Gas 消耗、失败原因。
- **告警**：失败率过高、亏损超阈值、节点异常。

## 3. 数据流与执行流程
1. 数据采集层获取最新池子状态与 mempool 交易。
2. 策略引擎生成候选套利路径。
3. 模拟模块验证收益与 Gas 成本。
4. 风控模块审批是否可执行。
5. 执行层构建交易并发送至私有/公共通道。
6. 监控模块记录执行结果，反馈策略调优。

## 4. 技术选型建议
- **语言**：Rust（高性能、低延迟）或 Go（工程效率）。
- **节点**：自建 Geth/Erigon + 第三方 RPC 冗余。
- **数据库**：PostgreSQL（审计与交易记录）、Redis（缓存）。
- **监控**：Prometheus + Grafana。

## 5. 安全性设计
- 多签与权限分离。
- 策略与执行模块分权部署。
- 关键参数修改需审计。

## 6. 部署与运维
- Docker 容器化。
- 自动化部署（CI/CD）。
- 灰度发布与回滚机制。
