# MEV 机器人需求文档（EVM 兼容链）

## 1. 背景与目标
- 目标：构建面向 EVM 兼容链（如 Ethereum、BSC）的链上 MEV 机器人，支持多策略（DEX 套利、清算、三明治/夹子控制、闪电贷套利、跨池路由等），在保证风控与合规的前提下实现稳定收益。
- 业务范围：链上 DEX/借贷协议、MEV 保护/交易通道、Flashbots / 私有交易通道、RPC 与数据基础设施。

## 2. 关键利益相关者
- 交易策略团队：负责策略逻辑、参数调优。
- 区块链工程团队：负责链上交互、合约与执行。
- 基础设施团队：负责节点、数据源、监控与告警。
- 风控/合规：负责风险、链上合规、资金安全。

## 3. 需求范围（Scope）
### 3.1 包含
- 多链支持：Ethereum 主网、BSC（后续扩展至 Arbitrum/Polygon 等）。
- 策略支持：
  - DEX-DEX 套利（多池/多路径）
  - 闪电贷套利（Aave/Uniswap V2/V3/其他支持的借贷池）
  - 借贷协议清算（Aave/Compound 等）
  - Backrun / 反夹攻击保护型交易
- 执行通道：公共 mempool + 私有交易通道（Flashbots/MEV-Share/自建 relay）。
- 风控模块：限额、止损、nonce 管理、Gas 策略与失败补偿。

### 3.2 不包含
- 中心化交易所（CEX）套利与法币出入金流程。
- 前端产品与用户界面（以服务/CLI 为主）。

## 4. 功能性需求
1. **链上数据采集**
   - 支持订阅新区块、mempool 交易、DEX 池状态、价格预言机（Chainlink）。
   - 快速同步池子状态（V2/V3），支持 tick/流动性信息缓存。

2. **策略引擎**
   - 策略模板：
     - 两池/三池套利
     - 同协议多池套利（V2/V3/稳定池）
     - 闪电贷套利（必须显式计算利息与手续费）
     - 清算策略（基于健康因子阈值）
   - 可配置参数：最小收益阈值、最大 Gas、最大借贷金额、最大滑点。

3. **执行与交易构建**
   - 交易打包（bundle）与私有提交。
   - 支持预先模拟（eth_call / tenderly 类）进行利润验证。
   - 支持多次重试与撤销（取消交易或置换交易）。

4. **风险控制与资金管理**
   - 基于资产池/策略的限额。
   - 最大回撤与冷却时间。
   - 失败交易的自动熔断与报警。

5. **监控与告警**
   - 监控收益、成功率、Gas 消耗、失败原因。
   - 报警渠道（Slack/Telegram/邮件）。

6. **日志与审计**
   - 结构化日志存储（JSON 日志）。
   - 关键执行链路可审计（策略 -> 模拟 -> 发包 -> 上链结果）。

## 5. 非功能性需求
- **性能**：mempool 延迟 < 50ms（本地/近节点）。
- **可靠性**：策略服务 99.9% 可用；节点冗余。
- **安全性**：私钥托管 HSM/硬件签名（如 Ledger/自托管安全模块）。
- **扩展性**：支持新增 DEX、链与策略。
- **合规与风控**：避免恶意夹子攻击策略，确保符合交易所/合约条款。

## 6. 约束与假设
- 节点访问可用且稳定（自建或高质量 RPC）。
- 交易执行需要考虑链上拥堵与 Gas 费用波动。
- 需要与 MEV relayer 生态兼容。

## 7. 里程碑计划
1. POC：单链（ETH）两池套利 + 私有发送渠道。
2. MVP：加入闪电贷套利 + 风控模块。
3. Beta：支持多链与监控系统。
4. Production：全自动执行 + 审计与合规评估。

## 8. 验收标准
- 可在测试网成功执行 100+ 笔套利交易，成功率 > 70%。
- 单次套利平均净收益为正，且最大亏损受控。
- 系统日志与监控可追溯、可报警。
